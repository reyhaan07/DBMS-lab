## Other files
- `EXAM_CHEATSHEET.md`: one page to read the morning of the exam.
- `solutions/01–08_*.sql`: complete answers for every question in the 8 schemas from the question sets.
- `solutions/09_procedures_functions.sql`, `10_triggers.sql`, `solutions/xml/`: procedures, functions, triggers and XML/XSD.

All SQL was tested on MariaDB 10.11 (MySQL-compatible).

`video_build/` holds the scripts that generated the videos.
